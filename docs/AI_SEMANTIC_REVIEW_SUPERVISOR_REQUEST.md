Status: **PROPOSED, NOT APPROVED.** Prepared 28 October 2026. This file is a request for a genuine supervisor decision, not an approval artifact, reviewer identity or signature. No message has been sent to a supervisor.

The current policy requires independently human-reviewed English/Lean pairs before dataset eligibility. The requested alternative would use an explicitly disclosed AI audit for proposition-level screening, exact Lean reference checks, automated mathematical probes and supervisor-directed adjudication. It would replace universal first-pass human review only if expressly accepted; it would not rename AI outputs as human decisions.

The evidence package is `data/ai_semantic_audit/20261028/`, with the assembled per-item records, proposed dataset and disagreement ledger under `delivery/`. The primary experimental model remains Qwen2.5-7B-Instruct-4bit. Both the model/prompt revision and invalid/unfavorable responses remain disclosed.

Other responses copy prompt placeholders or fail the JSON schema. Those outputs remain in the package, with their source hashes and unresolved status. Accordingly, the present evidence does not support blanket AI certification or an automatic replacement of independent expert review.
