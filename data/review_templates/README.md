# Research dataset review templates

`research_candidate_review_template_v0.1.0.json` is a blank worksheet for
record-level source/license, semantic, theorem, assumption, self-containment,
category/difficulty, family/split, and duplicate review. Copy it into a
review-controlled workspace for each candidate; do not use the blank template
as evidence of review. Record the actual independent reviewer pseudonym or ID,
date, decision, and evidence only after that review occurs. The project's
dataset validator remains the machine-readable eligibility gate.
