# Library-derived candidate extension

52 additional mathematical candidates, all reference-proof-verified in the pinned Lean 4.32.0 / Mathlib environment. This is a candidate pool, not an eligible benchmark. No source compatibility, semantic, family, category/difficulty, split or independent-review approval is implied.

English statements were authored as paraphrases/adaptations of the cited formal source declarations. They are not falsely attributed quotations. `candidate_records.json` records domains/assumptions, imports, theorem names, source-item URLs at immutable revisions, exact source and statement hashes, reference code and per-theorem axiom lists. Original source bytes, copyright headers and the applicable Apache-2.0 license texts are under `source_archive/`. Generated additive lemmas are identified as such.

`references_expanded.lean` and `verification_expanded.json` preserve the actual final batch command, complete JSON diagnostics, exit 0, exact source hash and 52 named axiom inspections. Earlier compilation attempts are retained separately. None is a model-generation experiment. The library proof verifier permits only propext, Classical.choice and Quot.sound; no placeholders are accepted in the successful batch.

All 52 proposed families require independent comparison with the original pool and with one another. Generalization relationships (including Fermat/Euler, square-root and logarithm/exponential claims) may cause regrouping or exclusion. Unique family strings do not establish statistical independence. Mathlib-derived and textbook-derived sources must be distinguished; source availability in a model's pretraining and access to named Mathlib lemmas are threats to validity.

The new candidates are provisionally reserved for test curation. No candidate in this batch was used for model selection, mathematical inference, prompt tuning or held-out evaluation. The Qwen backend was checked only with a neutral READY prompt.
